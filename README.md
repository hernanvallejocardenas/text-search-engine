# Text Search Engine

A small command-line search engine built on an inverted index, using only
the Python standard library.

## How it works

An inverted index maps each word to the documents that contain it, along
with the position of each occurrence. Searching a word means looking it up
in the index instead of scanning every document. A multi-word query returns
only documents containing every word (AND). Results rank by total term
frequency divided by the square root of the document length, so documents
that mention the query often rank higher while shorter documents still get
a fair chance. A query in double quotes is a phrase search: only documents
containing the exact phrase, in order, match.

Tokenization lowercases text and splits on anything that is not a letter or
a digit, so search is case-insensitive and punctuation-tolerant.

## Usage

Build the index from a directory of `.txt` files:

```
python search_engine.py index corpus
```

Search it:

```
python search_engine.py search "alice"
python search_engine.py search "sleepy hollow"
python search_engine.py search '"once upon a midnight dreary"'
```

The index is written to `index.json` (a build artifact, regenerated by the
`index` command). Each hit prints the document name, a relevance score,
and a short snippet showing the query in context.

## Example queries

```
$ python search_engine.py search "alice"
1 result(s) for "alice":
1. alices-adventures-in-wonderland.txt (score 2.30)
   The Project Gutenberg eBook of Alice's Adventures in Wonderland This eB...
```

```
$ python search_engine.py search "sleepy hollow"
2 result(s) for "sleepy hollow":
1. the-legend-of-sleepy-hollow.txt (score 0.38)
   The Project Gutenberg eBook of The Legend of Sleepy Hollow This eBook is for the use...
2. alices-adventures-in-wonderland.txt (score 0.03)
   ...he could, for the hot day made her feel very sleepy and stupid), whether the pleasure of m...
```

```
$ python search_engine.py search '"once upon a midnight dreary"'
1 result(s) for "once upon a midnight dreary":
1. the-raven.txt (score 0.02)
   ...VEN *** The Raven by Edgar Allan Poe Once upon a midnight dreary, while I pondered...
```

A word that appears in no document, and an empty query, both produce a
clear message instead of an error:

```
$ python search_engine.py search "quantum"
No documents match "quantum".

$ python search_engine.py search "   "
Empty query: type one or more words to search for.
```

## Tests

```
python -m unittest test_search_engine
```

17 tests, all passing. Coverage: indexing (terms in the right documents,
positions recorded), single-term search, multi-term AND search, ranking
order (more occurrences rank higher), missing terms, empty queries,
case-insensitivity, phrase search, snippet extraction, and loading
documents from a directory.

## Notes

- Python standard library only; no external dependencies.
- Requires Python 3.
